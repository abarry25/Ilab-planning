How to use this: The board covers Aug 1 2026 – Jul 31 2027 and opens on Full calendar in day view. Use the rail down the left to change what you're looking at: View switches between the full year and a single term (they're windows onto the same data, not separate boards — a date marked in one is the same mark in the others), Zoom flips between days and weeks, and Jump to takes you straight to today or any month. The month you're scrolled to stays pinned above the grid, and a rust-coloured line marks today.

Marking dates. Click any day to open that event — one row on one date, which is exactly one line of the ClickUp export. Clicking an empty day marks it and opens it in one go. To mark a run of days quickly, drag across the cells; to flip a single day without opening anything, Alt-click (⌥ on a Mac) it. In week view a click marks or clears the whole week. Click any row name to rename it, use + Add row to add one, and hover a row for the × to remove it (with an Undo).

Event fields. Every ClickUp column can be set at three levels, and the narrowest one that has a value wins. Set the common case once per bucket under Event fields → Bucket defaults; override it for a whole row with the ⚙ beside its name; override a single occurrence in the event editor. Blank always means "inherit", and the editor shows you in grey what a field would inherit if you leave it alone — plus a live Exports as preview of all 17 columns for that event. There's a (force blank) choice when you need to clear something an outer level set. Owner initials become ClickUp emails via Event fields → Who → email, which flags any initials it can't match. Dropdown choices are editable under Dropdown options.

Export. Tick the boxes on the rows you want and click Create ClickUp export — you get one line per marked date in the view you're currently on. Sort by any column header, filter with the boxes beneath them, and Download CSV gives you exactly the rows you've filtered to. Every bucket also carries a rollup strip on its header row showing every day it has something on, with a dot where three or more items stack up; clicking a filled square lists what's behind it. Milestones above the grid come from the FAS Registrar's calendar — check exact dates before locking programming around them. Group tags: MACRO = ecosystem events to track, FUNC = an operating rule, CORE = flagship programming, SERVICE = supporting programs. Drag the thin handle right of the name field to widen it (double-click to reset), or the handle at the far edge of the left panel to widen the whole names area.
